# sproutDoc

A simple plant tracking app created from my desperate attempts to keep houseplants alive...

A user will add their plants (growth progess photos, custom name, description, etc) and a call to Perenual API (https://perenual.com) will return the watering interval. The user's plants will be displayed as tiles in a list and a progess bar will indicate how long until the plant needs watered again, along with a date that water is needed again.
